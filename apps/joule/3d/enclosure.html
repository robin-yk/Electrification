Model boundaries
Supply resistance uses the mean element temperature, as in Joule2D. The 3D potential determines the spatial distribution of bulk heating, normalized to that supply budget. Fixed current/voltage settings report limit violations rather than silently clipping them.
Contact dissipation is counted as heat leaving through external leads, not deposited in the simulated domain. Gap radiation uses sector-local concentric-cylinder exchange, not a general 3D view-factor calculation. Flow is prescribed thermal transport, not CFD. Porosity uses the existing 2D effective-property conventions.
Axisymmetric agreement tests code consistency; it does not validate arbitrary asymmetric reactors. Actual rectangular geometry and offset electrodes remain available in the separate solid-only model. A rectangular import here requires the explicit 2D equivalent-cylinder approximation.
