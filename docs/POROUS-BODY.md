# Opt-in porous-body screening

Set `input.porousMode = "effective"` and supply a positive `input.effectiveK`
in W/(m K). The browser exposes both fields under Geometry. The mode is off
by default. Existing presets and archived calculations retain their prior
property treatment.

Legacy mode does not reduce 2D storage with solid fraction. It is retained
for compatibility, not endorsed for porous transients with skeleton density.
Use the new mode for that purpose.

## Closures

- Enter skeleton density, skeleton specific heat and skeleton electrical
  resistivity. Do not supply bulk density and then dilute it again.
- The cylinder API receives **solid** volume in `volumeCm3`. The browser
  converts envelope volume using `solidVolume = (1 - phi) * envelopeVolume`.
- Mass is skeleton density times solid volume. The 2D transient storage
  coefficient is `(1 - phi) * rho_s * cp_s(T)` per envelope volume. Pore-gas
  storage is neglected. The same coefficient enters the time step and its
  energy-residual accounting.
- Effective thermal conductivity is the user-specified, constant, isotropic
  body-scale value. This mode overrides the optional skeleton mixing rule;
  an effective conductivity must not be mixed a second time. Reassess this
  input when changing porosity. No porosity-to-conductivity law is implied.
- Resistance continues to use the solid cross-section. This is an axial
  parallel-path approximation with end-to-end current supply, not a resolved
  channel or foam network. The 2D electrical source retains the existing
  normalization to the scalar operating-point power.
- Internal channel flow, internal solid-gas heat exchange, reaction heat,
  directional conductivity and pore radiation are not added. The existing
  external gap/purge-gas calculation is unchanged. This is a porous heater
  screening mode, not a validated reacting-monolith model.

The storage closure follows solid-volume averaging with negligible gas
storage. See [COMSOL's porous heat-transfer theory](https://doc.comsol.com/6.4/doc/com.comsol.help.heat/heat_ug_theory.07.016.html).
An isotropic effective conductivity requires a measurement or a stated
approximation and sensitivity range; porosity alone does not establish it.
See [effective-conductivity models](https://doc.comsol.com/6.4/doc/com.comsol.help.heat/heat_ug_theory.07.018.html).

## Verification and figure status

Run `node --test tests/joule-transient.test.js` for the porous adiabatic
`P/(m cp)` ramp, storage closure, effective-k override and input validation.
Run `npm test` for legacy regressions. These tests verify implementation,
not experimental agreement for a monolith.

`storedEnergy` integrates the volumetric heat capacity from the reference
temperature to each cell temperature. Tabulated solid cp is integrated across
each linear segment and its constant endpoint extensions; gas storage uses
the integral of the existing bounded inverse-temperature coefficient. The
time integrator and its stepwise closure still use midpoint cp. Thus a coarse
step crossing cp-table knots can have an integration error even when its
discrete closure is small. Time-step refinement remains necessary.

Independent single-cell calorimetry and piecewise-cp tests are in the same
test file. This corrects the previous final-cp-times-temperature-rise energy
output, without changing the temperature solver or its accepted time steps.

No archived figure data is regenerated by this change. New porous-mode
figures need new calculations with the closures and property source recorded.
The previous dense-cylinder design does not validate this new mode.
