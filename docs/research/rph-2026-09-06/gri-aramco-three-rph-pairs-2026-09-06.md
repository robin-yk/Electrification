# GRI–Aramco RPH 세 조건 짝비교

후속 run 34077150687은 29분 계산 단계 제한으로 종료됐다. 12개 반응 계산 중 11개 완료 파일을 보존했다. 8300048의 Aramco 401구간 계산만 완료되지 않았다. 미수렴이 확인된 것이 아니라 완료 출력 전에 작업 시간 제한에 도달한 것이다. 세 조건 전체가 검증됐다고 말하지 않는다. 추가 재실행은 하지 않았다.

분모는 총 유입 탄소다. 첫 두 조건의 C₂H₂ 순위는 GRI와 Aramco 사이에서 역전된다. 세 번째 조건에서는 기본 격자 Aramco의 전체 C₆ 탄소수율이 25.6117%이고 대부분 벤젠이었다. 이 결과는 첫 두 고온 조건의 작은 벤젠 수율과 다르다. 아직 세분화 검증을 통과하지 않은 수치를 최종 최적화 데이터로 쓰지 않는다.

원본은 [통합 출력 폴더의 summary.json](data/three-rph-pairs-2026-09-06/summary.json)과 각 case JSON에 보관했다. 같은 폴더의 resume.log 마지막 START는 8300048-aramco-refined이고 완료 RESULT는 없다. 시간 제한의 근거는 Actions의 실패 로그다. 마지막 미완료 적분의 중간 상태를 저장하지 않아 그 계산량은 복구할 수 없다. 완료 case 캐시는 중간 적분 checkpoint를 대신하지 못했다.

아래는 실행 중 단계별 기록이다. 진행 중이라는 표현은 그 시점의 상태이며 위 최종 상태로 갱신됐다.

## 실행 기록

2026-09-06 미국 동부시간에 [Actions run 34075748186](https://github.com/robin-yk/Electrification-Suite/actions/runs/34075748186)을 시작했다. 커밋 e841b5d, 별도 브랜치 codex/three-rph-pairs-20260906. main은 변경하지 않았다. 기존 속도시험 run 34073602546과 별개의 계산이다.

사용자는 첫 조건 계산비를 확인한 뒤 총 60분 한도로 세 조건 완료를 승인했다. 첫 실행은 24분 50초에 의도적으로 종료했고, 완료된 파일의 artifact 업로드가 성공했다. 수치 검증 실패가 아니라 기존 작업의 30분 제한을 피하기 위한 이어 실행이다. [후속 run 34077150687](https://github.com/robin-yk/Electrification-Suite/actions/runs/34077150687), 커밋 f6a423e, 브랜치 codex/three-rph-pairs-resume-20260906에서 기존 출력의 원본 커밋·해석기 파일·Cantera 버전·메커니즘 해시·입력값·통과 기준을 검사하고 완료된 계산을 재사용했다. 두 번째 조건 Aramco 400구간부터 이어 실행 중이다. 최소 주기 수와 수렴·격자 검증 기준은 유지했다.

재현 명령은 저장소 루트에서 `python tools/openmkm_dynamic/run_three_pairs.py`이다. 실행 전 generator, run card, workflow를 커밋했다. 최신 main을 기준으로 전체 Node 테스트 106개가 통과했다. 이는 소프트웨어 회귀검사이며 화학 메커니즘의 실험 검증은 아니다.

## 비교 질문과 조건

GRI에서 선택한 세 조건을 같은 물리 온도 파형과 시간격자로 AramcoMech 2.0에 넣었을 때 C₂ 수율과 조건 순위가 얼마나 달라지는지 확인한다. C₆ 생성 가능성을 새로 묻는 시험이 아니다. Aramco가 포함하는 C₆ 경로의 결과를 전체 탄소수지 안에서 집계한다.

| design index | CH₄/CO₂ 몰비 조성 | 주기 (s) | duty | 체류시간 (s) | 성격 |
|---|---|---:|---:|---:|---|
| 6300012 | 0.8/0.2 | 0.1 | 0.85 | 0.01 | 고온, 짧은 체류시간 |
| 6000015 | 0.8/0.2 | 0.1 | 0.85 | 0.1274275 | 같은 파형, 긴 체류시간 |
| 8300048 | 0.701625/0.298375 | 2.8068066 | 0.06574446 | 6.1181032 | 큰 온도 진폭, 낮은 duty |

정확한 값은 원본 JSONL과 실행 artifact의 source 파일에 보관한다. 앞 두 조건의 전압은 34.23076923 V, 세 번째는 33.75596842 V이며, 기존 element model에 주변온도 25 °C를 주어 주기 정상상태 파형을 재구성한다.

## 모델과 수율 정의

기존 constant-pressure CSTR 코드를 그대로 사용한다. 압력은 1 atm, 온도는 지정된 시간함수이며 반응기의 에너지방정식은 풀지 않는다. 매 구간에서 유입·유출 질량유량을 순간 반응기 질량/체류시간으로 같게 설정한다. 실제 고정 유입유량 장치 또는 전기–열–화학 완전결합 모델로 해석하지 않는다.

GRI는 dense, Aramco는 sparse 해법을 사용한다. 두 메커니즘에 동일한 온도 격자를 적용하고, 기본 격자 200개와 400개를 비교한다. 기존 고온 구간 추가 분할도 적용하므로 실제 구간 수는 별도로 기록한다.

성분별 탄소수율은 한 주기 동안 유출된 해당 성분의 탄소 몰수를 같은 주기의 총 유입 탄소 몰수로 나눈다. CH₄ 전환량 기준 선택도와 다르다. C₂H₂, C₂H₄, C₂H₆, C₆H₆, CO 및 전체 C₂·C₆ 그룹을 저장한다. GRI에 C₆ 종이 없는 것은 모델 범위 제한이며, 물리적으로 벤젠이 생성되지 않는다는 증거가 아니다. soot는 계산하지 않는다.

## 통과 기준과 중단 조건

무반응 저온 한계에서 전환율 0을 먼저 확인한다. 이후 각 계산은 최소 20주기, 최대 100주기이며 전체 종의 주기 경계 질량분율 최대 차이 10⁻⁸ 미만을 요구한다. 전체 유출 종의 질량 합 검사, 반응기 재고 변화를 포함한 C/H/O 수지, 전체 탄소 그룹 합 검사를 수행한다.

C/H/O 수지 잔차는 각 원소 유입량의 0.5% 미만, 질량 분할 잔차는 10⁻⁶ 미만이다. 격자를 두 배로 세분했을 때 탄소수율 절대차는 max(0.002, 세분화 결과의 2%) 이내이고 CH₄ 전환율 절대차는 0.002 이내여야 한다. 이는 pilot의 수치 통과 기준이며 실험 정확도를 의미하지 않는다.

하나의 검증이 실패하면 다음 조건을 실행하지 않는다. 최대 12개 반응 계산과 저온 검사 1개이며 원격 작업 제한은 30분이다. 계산비를 추정한 초기 5–20분 범위는 실측 결과로 갱신해야 한다.

## 결과 상태

현재 원격 계산 진행 중. 수율 비교와 순위 판정은 미완료다. 무반응 검사와 첫 GRI 기본 격자 결과가 원격 로그에 기록됐다. 최종 결과 및 중단 사유는 같은 artifact의 status.json과 summary.json으로 확인한다.

### 중간 출력: 6300012, 기본 200구간

아래는 Actions 실시간 로그에서 확인한 기본 격자 계산값이다. 이후 400구간 결과도 완료되어 첫 조건은 설정한 수치 검증 기준을 통과했다. 두 메커니즘의 기본·세분화 계산 모두 20주기 후 주기 경계 수렴 및 원소수지 기준을 통과했다.

| 지표 | GRI | Aramco |
|---|---:|---:|
| CH₄ 전환율 (%) | 91.1235 | 93.2261 |
| C₂H₂ 탄소수율 (%) | 62.3005 | 49.4301 |
| C₂H₄ 탄소수율 (%) | 0.3271 | 0.3028 |
| 전체 C₂ 탄소수율 (%) | 62.6678 | 49.7680 |
| C₆H₆ 탄소수율 (%) | 모델에 없음 | 0.2884 |
| 전체 C₆ 탄소수율 (%) | 모델에 없음 | 0.7867 |
| CO 탄소수율 (%) | 28.5650 | 33.7331 |
| solver wall time (s) | 17.4785 | 348.0796 |

탄소수율의 분모는 CH₄와 CO₂를 합친 총 유입 탄소다. Aramco에서 C₂H₂ 수율은 낮고 CH₄ 전환율은 높다. 전체 C₆ 수율만으로 C₂ 감소분을 설명할 수 없다. CO 및 나머지 탄소수 그룹의 차이를 함께 확인해야 한다. 두 메커니즘의 차이는 C₆ 경로 유무만이 아니므로 C₆ 경로의 단독 인과효과라고 단정하지 않는다.

400구간의 Aramco C₂H₂ 탄소수율은 0.4943011406596128, C₆H₆는 0.00288345483262494, 전체 C₆는 0.007867213911046429, CO는 0.33733133748693156이다. CH₄ 전환율은 0.9322611993759968이다. C₂H₂ 탄소수율의 200→400구간 절대차는 약 9.59×10⁻⁸이다. 세분화 Aramco solver wall time은 622.8561초이며, 첫 조건 한 쌍의 기본·세분화 검증에 약 17분이 들었다. 기존 속도시험 결과를 이 조건의 완료 비용으로 사용할 수 없다.

원본 전체 종 출력에서 첫 조건 Aramco의 C₃ 탄소수율은 1.60789%, C₄는 7.43520%, C₅는 0.00165%, C₆는 0.78672%였다. C₄의 대부분은 C₄H₂였고, C₆의 최대 기여 종은 C₆H₂였다. 전체 C₆를 벤젠으로 부르면 안 된다. 이번 CH₄–CO₂ 조건에서 C₄ 기여는 C₆보다 크다.

GRI는 200·400구간 모두 완료됐고, Aramco는 200구간이 완료됐다. Aramco 400구간 검증 전 상태다.

|---|---:|---:|

| C₂H₂ 탄소수율 (%) | 59.1549 | 50.6856 |

| 전체 C₂ 탄소수율 (%) | 59.3909 | 50.9010 |

기본 격자의 Aramco 결과는 GRI와 반대의 체류시간 순위를 보인다. 같은 온도 파형에서 체류시간을 늘리면 GRI의 C₂H₂ 탄소수율은 낮아지지만 Aramco에서는 높아진다. 최종 순위 판단은 Aramco 400구간 검증 이후로 남긴다.

### 계산비 기록

완료 파일의 수렴 이력을 보면 첫 조건의 주기 경계 잔차는 두 번째 주기, 두 번째 조건 Aramco 기본 계산은 세 번째 주기에 이미 10⁻⁸ 아래였다. 이번 실행은 최소 20주기를 강제해 더 오래 계산했다. 따라서 실측 17분에는 검증용 최소 주기 설정의 비용이 포함된다. 이 시간이 해당 조건의 불가피한 최소 계산비라고 주장하지 않는다. 향후 최소 주기 수를 줄이려면 초기에 얻은 주기 수율과 전체 20주기 결과의 일치도 함께 확인해야 한다.

후속으로 경계 상태와 전체 주기 유출량을 3회 연속 검사하는 조기 종료 정책을 구현하고 검증했다. Aramco 두 조건이 각각 5·6주기에 끝났고 기존 20주기 탄소수율과의 최대 절대차는 약 1.55×10⁻¹¹이었다. 원래 세 조건 계산에는 소급 적용하지 않았다. 구현·검증·장기 운영 설계는 [계산비·토큰 절감 운영 설계](low-cost-research-operations-2026-09-06.md)에 기록했다.

완료 결과는 이 문서에 후속 기록한다. 원본 artifact 이름은 three-rph-pairs이며, 전체 종 출력·수지·수렴 이력·온도 파형·원본 입력·해시를 포함한다.
